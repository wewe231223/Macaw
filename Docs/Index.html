빌드

DOCUMENTATION

문서 생성

PowerShell 7이 필요합니다. 저장소 루트에서 다음 명령을 실행합니다. Windows x64에서는 -InstallTools 옵션으로 지정된 버전의 Doxygen과 Graphviz를 다운로드합니다.

pwsh -File Scripts/BuildDocumentation.ps1 -InstallTools

Linux x64에서는 Graphviz를 먼저 설치합니다. Ubuntu·Debian:

sudo apt-get install graphviz

생성된 문서의 시작 페이지:

Build/Documentation/Site/index.html

최초 설치 후에는 -InstallTools를 생략할 수 있습니다. C++ 빌드는 필요하지 않습니다.

ENGINE

엔진 빌드

Windows, Visual Studio C++ 개발 도구, Windows SDK, Git, Premake 5가 필요합니다. 저장소 루트에서 설치된 Visual Studio 버전에 맞는 Premake 액션으로 프로젝트를 생성합니다.

프로젝트 생성 시 의존성 설치 스크립트가 실행됩니다. 수동 실행 명령:

powershell.exe -NoProfile -ExecutionPolicy Bypass -File Scripts/setup-deps.ps1

생성된 솔루션에서 플랫폼 x64, 구성 Debug, Release 또는 Viewer를 선택하고 Macaw를 빌드합니다. 출력 경로는 bin/<구성>/x64/Macaw.exe입니다.

실행 시 작업 디렉터리는 저장소 루트로 설정합니다. 초기화 코드에서 ./Content/의 리소스를 상대 경로로 읽습니다.
