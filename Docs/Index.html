DOCUMENTATION

문서 생성

PowerShell 7이 필요합니다. 저장소 루트에서 다음 명령을 실행합니다. Windows x64에서는 -InstallTools 옵션으로 지정된 버전의 Doxygen과 Graphviz를 다운로드합니다.

pwsh -File Scripts/BuildDocumentation.ps1 -InstallTools

Linux x64에서는 Graphviz를 먼저 설치합니다. Ubuntu·Debian:

sudo apt-get install graphviz

생성된 문서의 시작 페이지:

Build/Documentation/Site/index.html

최초 설치 후에는 -InstallTools를 생략할 수 있습니다. C++ 빌드는 필요하지 않습니다.

ENGINE

엔진 빌드

Windows, Visual Studio C++ 개발 도구, Windows SDK, Git, Premake 5가 필요합니다. 저장소 루트에서 다음 명령으로 리플렉션 코드와 프로젝트를 생성하고 빌드합니다.

pwsh -File Scripts/Build.ps1 -Configuration Debug
pwsh -File Scripts/Build.ps1 -Configuration Release

소스는 Source/<모듈>/Public과 Private에 있습니다. 생성된 리플렉션 코드는 Intermediate/<모듈>/Generated/에 있으며 앱은 Intermediate/Macaw/Generated/를 사용합니다.

플랫폼은 x64, 구성은 Debug 또는 Release입니다. 실행 파일은 Binaries/<구성>/Macaw.exe입니다.

실행 시 작업 디렉터리는 저장소 루트로 설정합니다. Documentation Actions는 PR에서 문서를 검증하고 기본 브랜치에서 GitHub Pages에 배포합니다.
